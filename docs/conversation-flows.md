# LINE 對話流程

## 首次加入

私人聊天收到 `follow` 後，科米蛙會先顯示服務選擇。選擇「記帳中心」後，科米蛙會提供設定說明與完整範本；使用者複製範本、增刪可自訂的項目後，一次完整回傳即可。

收入與支出的前兩層記帳分類，以及付款方式（現金、信用卡）都是固定項目，不能異動。收入／支出下以 `▪` 開頭的記帳子分類、及付款方式下以 `◦` 開頭的付款工具可以自由增刪，且沒有一次 30 項的數量限制。格式正確時，科米蛙會先回覆確認訊息，再顯示完整設定內容供確認儲存或重新設定。

設定流程保留七天；再次開啟設定時會顯示已解析的確認內容。只有明確選擇「重新設定」才會清除尚未確認的內容。

## 群組加入

Bot 收到 `join` 後建立群組帳本及固定記帳分類。群組記帳分類共用；任何成員均可設定。付款工具屬於個人，成員須先加 Bot 好友並完成私人設定，才能在群組開始記帳。

若客戶端未顯示 Rich Menu，可輸入「選單」或「記帳」，也可提及 Bot。Bot 在沒有進行中流程時不回應一般群聊。

## 新增交易

1. 選擇記收入或記支出。
2. 選擇記帳分類；有記帳子分類時可以繼續下鑽或使用目前記帳分類。
3. 選擇付款方式：現金或信用卡。
4. 選擇個人付款工具，或直接使用付款方式。
5. 輸入 TWD 正整數金額。
6. 檢查日期、記帳分類、付款方式、付款工具、金額與備註。
7. 選擇確認、修改或新增備註。

動態按鈕綁定對話 ID 與 revision；點擊舊訊息中的按鈕不會操作新的草稿。

## 設定中心

完成初始化後，設定入口可：

- 再次批次新增各固定記帳分類下的記帳子分類。
- 瀏覽、改名或停用自訂記帳分類。
- 在自訂記帳分類下建立任意深度的記帳子分類。
- 私聊中瀏覽、改名或停用個人付款工具。

已被交易使用的記帳分類或付款工具只會停用，歷史交易仍顯示當時的完整名稱。

## 群組權限

- 所有成員可新增、修改一般欄位或刪除群組交易。
- 只有付款人能修改付款方式與付款工具。
- 被選用的完整付款工具名稱會顯示在群組交易中。
- 所有變更均寫入審計紀錄。
